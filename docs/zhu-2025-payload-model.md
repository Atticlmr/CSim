## 1. 论文的模型假设

论文把吊载视为质点，绳索无质量且不可伸长，并假定全过程张力非负；悬挂点位于无人机质心。
这是固定绳长的摆动模型，不包含松绳后的自由飞行及重新绷紧冲击。
引入 SPAD 后，绳长仍然恒定；作者所说“包含绳索弹性等因素的影响”是等效拟合含义，没有新增弹簧伸长自由度。

CSim 的绷紧分支采用更明确的运行条件 `T>0`；到达 `T<=0` 时报告模式边界。
在实现松绳事件前，不能截断负张力并继续沿用绷紧方程。

## 2. 四个坐标系与摆角

| 论文坐标系 | 原点、方向与用途 |
| --- | --- |
| W | 地面固定参考系；图 1 和重力项表明 Z 向下，水平轴未规定为地理北、东 |
| B | 无人机质心；X 向前、Y 向右、Z 向下，即 FRD |
| S | 悬挂点；随无人机平移，三个轴始终与 W 平行，`R^W_S=I` |
| P | 吊载质点；Z 轴从悬挂点指向吊载，其余轴由绳方向构造，用于切向/径向投影 |

S 是随悬点加速平移的非惯性系，但不随机体转动。因此它需要平移惯性力 `-m_p*a_S`，不需要由 S 转动引起的科里奥利项。
P 是计算用的随绳方向坐标，不是具有独立姿态自由度的刚体吊载。
本文不把论文 W 自动称为地理 NED。

用 `a=alpha_x`、`b=alpha_y` 简写，论文式 (55) 给出相对悬点的位置：

```text
r_S = L*s_S
s_S = (cos(a)*sin(b), sin(a), cos(a)*cos(b))
```

`alpha_x` 描述绳索偏离 X–Z 平面的有符号角，`alpha_y` 描述绳索在 X–Z 平面的投影相对向下 Z 轴的角。
符号以这个位置公式为准，不能把它们直接当成无人机 roll、pitch。

定义两个切向基向量及径向向量：

```text
e_a = d(s_S)/da = (-sin(a)*sin(b), cos(a), -sin(a)*cos(b))
e_b = (cos(b), 0, -sin(b))
e_r = s_S

R^P_S = [ -e_a^T ]
        [  e_b^T ]
        [  e_r^T ]
```

该矩阵就是式 (3)，把 S 分量变换到 P 分量；反向变换用转置。
P 的 X 轴对应 `-e_a`，因此 X 向阻力在 `alpha_x` 方程中的符号与直觉上直接“加阻尼”不同。
从原文叉乘方向构造坐标轴时还需归一化。
摆角方程包含 `1/cos(a)` 与 `tan(a)`，在 `cos(a)=0` 处奇异；CSim 的三维核心继续使用单位绳方向，摆角用于对照和输出。

## 3. 从受力与几何得到摆动方程

### 3.1 相对速度与吊载绝对速度

由位置求导即可整理出式 (50)：

```text
r_dot_S = L*(e_a*a_dot + cos(a)*e_b*b_dot)
v_payload_W = v_quadrotor_W + R^W_S*r_dot_S
```

风速为零时，吊载对地速度可以作为空气相对速度使用。
移动悬点时，不能仅用 `r_dot_S` 计算论文中的阻力；无人机平移也贡献吊载绝对速度。

### 3.2 在 S 中列 Newton 方程

记 `T=F_pc` 为非负张力大小、`F_d_S` 为作用于吊载的等效阻力、`a_S` 为悬点对惯性系的加速度，论文采用向下重力：

```text
m_p*r_ddot_S = -T*s_S + m_p*g*e3 - m_p*a_S + F_d_S
```

这里的左侧是相对悬点的加速度；若改在惯性系写吊载绝对加速度，就应移除右侧的平移惯性力，避免重复计算悬点加速度。

### 3.3 投影到 P

将上式与 `r_S` 的二阶导数分别左乘 `R^P_S`。几何加速度整理为论文式 (60)：

```text
r_ddot_P.x = -L*a_ddot - L*b_dot^2*sin(a)*cos(a)
r_ddot_P.y =  L*b_ddot*cos(a) - 2*L*a_dot*b_dot*sin(a)
r_ddot_P.z = -L*(a_dot^2 + b_dot^2*cos(a)^2)
```

切向分量不含张力，分别给出两个摆角加速度；径向分量给出张力。
这也是为什么张力是代数求出的约束反力，不需要独立积分。

### 3.4 整理结果

设 `(ax,ay,az)=a_S`、`(Dx,Dy,Dz)=F_d_P=R^P_S*F_d_S`，式 (4)–(6)／(62)–(64) 可写为：

```text
a_ddot = (ax*sin(a)*sin(b) - ay*cos(a)
          + (az-g)*sin(a)*cos(b) - Dx/m_p)/L
          - b_dot^2*sin(a)*cos(a)

b_ddot = (-ax*cos(b) + (az-g)*sin(b) + Dy/m_p)/(L*cos(a))
          + 2*a_dot*b_dot*tan(a)

T = m_p*(-ax*cos(a)*sin(b) - ay*sin(a) - az*cos(a)*cos(b)
         + g*cos(a)*cos(b) + L*(a_dot^2+b_dot^2*cos(a)^2)) + Dz
```

竖直静止、固定悬点且阻力为零时，得到 `a_ddot=b_ddot=0`、`T=m_p*g`。
固定悬点、只沿一个平面摆动且关闭阻尼时，退化为 `theta_ddot=-(g/L)*sin(theta)`。
阻力的径向分量也影响张力，不能只修改两个摆角方程而保持原无阻尼张力公式。

## 4. SPAD 与综合阻力

### 4.1 论文公式与物理解释

论文式 (7)、(49) 在 W/S 中计算阻力，再投影到 P：

```text
F_d_W = -0.5*K2*norm(v)*v - K1*v - K0*sgn(v)
F_d_P = R^P_S * F_d_W              # W 与 S 的轴平行
```

SPAD 是 **sign of the payload airspeed-dependent** 项，即 `-K0*sgn(v)`。
作者把它作为零阶等效阻力，用来集中拟合连接处干摩擦、绳索等因素造成的附加衰减。
当速度趋近零时，线性项按速度下降，二次项按速度平方下降，SPAD 的非零分量则保持有限幅值，因而更容易拟合小摆幅尾段。
它是经验耗散项，不能据此认为已显式建模关节静摩擦、弹性储能或绳索伸缩。

原文只写向量 `sgn(v)`，没有进一步说明向量符号函数的实现。
**CSim 复现约定**为逐分量符号函数：`sgn(v)=(sign(vx),sign(vy),sign(vz))`，且 `sign(0)=0`。
这不是单位方向 `v/norm(v)`：前者通常不与 v 严格共线，也不在任意旋转下保持各向同性。
复现时必须固定计算该项的坐标轴，不能先在机体系逐分量取符号，再当成与世界系计算等价。

### 4.2 量纲与论文参数

按公式使每一项均为力，系数单位必须为：

| 参数 | CSim 单位 | 含义 |
| --- | --- | --- |
| K2 | N·s²/m²，即 kg/m | 含式中 `1/2` 约定的二次阻力系数 |
| K1 | N·s/m，即 kg/s | 线性阻力系数 |
| K0 | N | SPAD 等效阻力幅值 |

论文表 II 把三种系数都列为 N·s/m，与式 (7) 的量纲不一致；此处单位由方程重新推导，不照抄表列单位。
若另一实现将二次项写成 `-c2*norm(v)*v`，则 `c2=K2/2`，不能直接复制 K2。

表 II 给出 `m_q=1.220 kg`、`m_p=0.157 kg`、`L=0.45 m`、`g=9.80 m/s²`。
表 III 的系数是五组分别辨识的结果，不能把不同组中的系数混合成新的“论文参数”：

| 论文模型 | K2 | K1 | K0 |
| --- | --- | --- | --- |
| Linear | 0 | 0.0060 | 0 |
| Quadratic | 0.0230 | 0 | 0 |
| Linear+SPAD | 0 | 0.0034 | 0.0010 |
| Quadratic+SPAD | 0.0083 | 0 | 0.0015 |
| Integrated | 0.0017 | 0.0028 | 0.0011 |

表 III 中，Linear+SPAD 与 Integrated 的摆角 RMSE 均约为 0.012 rad，Linear 约为 0.017 rad，Quadratic 约为 0.029 rad。
正文关于小于 0.1 rad 时 0.5%、21.8%、51% 的比较是该实验尾段峰值处的误差，不是全轨迹精度保证。
论文还报告该算例扰动谱主要位于约 0–3 Hz，峰值约 0.85 Hz；这是识别实验下的结果，不应直接变成所有无人机的内环带宽、控制频率或延迟参数。
当前项目未拿到原始实验轨迹，不能宣称已复现这些辨识精度。

### 4.3 空速、风与等效摩擦的边界

正文称 v 为空速，附录式 (49) 后却将其定义为相对地面的速度。
**无风复现时两者一致；引入风场属于 CSim 明确记录的扩展**：

```text
v_air_W = v_L_W - wind_velocity_W(p_L_W, time)
F_d_W = -0.5*K2*norm(v_air_W)*v_air_W - K1*v_air_W - K0*sgn(v_air_W)
```

当前实现使用标量、非负、有限的 K2/K1/K0，不擅自把表 III 的拟合参数推广为各向异性矩阵。
把 SPAD 也按空速计算只是保持这套等效阻力形式的一种约定；真实接头摩擦取决于相对转动而非风速。
移动悬点、有风和不同接头条件下需重新辨识、验证，不应把固定悬点实验的 K0 当作普适常量。
若以后单独加入关节摩擦力矩或绳索材料耗散，应重新评估 SPAD 系数，避免同一种衰减被重复计入。

## 5. 转换到 CSim 并闭合无人机—吊载耦合

### 5.1 坐标转换

为与 [CSim 建模约定](modeling-conventions.md) 对齐，取论文与 CSim 的参考 X 轴相同：

```text
C = diag(1,-1,-1)        # 论文局部 Z-down 世界系 -> CSim 局部 Z-up 世界系
D = diag(1,-1,-1)        # FRD -> FLU 机体系

v_CSim_W = C*v_paper_W
R_CSim_WB = C*R_paper_WB*transpose(D)
Omega_CSim_B = D*Omega_paper_B
s_CSim_W = (cos(a)*sin(b), -sin(a), -cos(a)*cos(b))
```

这是右手系之间绕 X 轴半转的转换；仅翻转 Z 会得到反射，不能作为姿态旋转。
水平参考方向不同时，还需指定额外航向变换。
在 `a=0` 的 X–Z 平面中，`b` 正好对应当前单摆文档中从竖直向下朝 +X 的摆角。
论文图 2 辨识的是以 `a` 为主的另一个竖直平面，比较时需显式对应平面和角度符号。

### 5.2 单位绳方向形式：CSim 推导

以下是按本项目 Z-up 约定重新推导的等价绷紧模型；无阻力基准以及两端空气力均已编码；任意外力回调接口尚未开放。
令 `s` 从无人机质心指向吊载，`omega_c·s=0`，`l=L`：

```text
p_L = p_Q + l*s
s_dot = omega_c × s
v_L = v_Q + l*(omega_c × s)

G = (0,0,-g)
F_Q = R_WB*(0,0,f) + F_external_on_quadrotor_W   # 不含绳力、重力
F_L = F_d_W + F_external_on_payload_W           # 不含绳力、重力

m_Q*a_Q = m_Q*G + F_Q + T*s
m_L*a_L = m_L*G + F_L - T*s
```

对固定绳长约束二次求导有 `s·(a_L-a_Q)=-l*norm(s_dot)^2`，故可消除隐含的悬点加速度和张力循环依赖：

```text
T = [s·(F_L/m_L - F_Q/m_Q) + l*norm(s_dot)^2] / (1/m_L + 1/m_Q)
a_Q = G + (F_Q + T*s)/m_Q
omega_c_dot = (1/l) * s × (F_L/m_L - F_Q/m_Q)
```

重力在相对加速度中抵消，但没有从两者的绝对运动方程中消失。
若悬点轨迹是外部给定的，则应使用另一种边界条件：

```text
T = m_L*(s·(G-a_A) + l*norm(s_dot)^2) + s·F_L
omega_c_dot = (1/l)*s × (G-a_A+F_L/m_L)
```

不能把固定悬点公式中的 `a_A=0` 用于自由飞行无人机。
在静止悬停、无阻尼时，自由耦合式给出 `f=(m_Q+m_L)*g`、`T=m_L*g`。

无人机角动力学仍使用已有刚体方程。因为悬点在质心，轴向绳力不直接产生机体力矩；SPAD 通过吊载受力、张力和相对摆动影响无人机平移。
这个经验模型把 SPAD 当作作用于吊载的外部等效力，不额外给无人机再施加 `-F_d_W`。
若改成真实接头摩擦模型，应独立建立内部力矩及其反作用，不能混用两种受力解释。

### 5.3 论文中的无人机控制简化模型

论文式 (8) 将绳张力转换到无人机机体系，式 (9)–(11) 在机体系写平移动力学，包含机体旋转带来的 `-Omega_B×v_B` 项。
后续式 (12)–(17) 以虚拟加速度输入和总扰动组织外环设计，内环由实际飞控承担。
这种控制用简化不能替代 CSim 已实现的六自由度刚体，更不能直接令物理加速度等于指令加速度。
在 CSim 中，应先计算推力、机体姿态、阻力和绳力，再形成外环需要的等效扰动量。
CTBR、单旋翼推力以及内环、延迟的分层设计见 [控制接口与响应模型](control-and-response-models.md)。

## 6. 已实现的可选阻尼配置

统一使用 DragConfig 的系数组合，不额外维护重复的模型枚举：

| 物理组合 | Python 配置 |
| --- | --- |
| 无阻尼（默认） | `csim.DragConfig()` |
| 线性 | `csim.DragConfig(k1=...)` |
| 二次 | `csim.DragConfig(k2=...)` |
| Linear+SPAD | `csim.DragConfig(k1=..., k0=...)` |
| Quadratic+SPAD | `csim.DragConfig(k2=..., k0=...)` |
| Integrated | `csim.DragConfig(k2=..., k1=..., k0=...)` |

将其传入 `SuspendedPayloadModel(payload_drag=...)` 或 `load_model(..., payload_drag=...)`。
未指定系数为零，不会隐式采用论文参数。系数全零保持原无阻尼计算分支，K0=0 不计算 SPAD。
无人机只允许 k1/k2；吊载允许三项。配置与控制输入模式、执行器响应独立，CTBR 不自动启用 SPAD。
例如表 III 的 Linear+SPAD 可显式配置 `csim.DragConfig(k1=0.0034, k0=0.001, sign_mode="exact")`；
系数适用范围仍受第 4 节说明限制。

### 6.1 不连续项与数值选项

启用 K0 后，实验配置必须明确记录 `sign_mode`：

| `sign_mode` | 定义 | 语义 |
| --- | --- | --- |
| `exact` | 逐分量 sign，sign(0)=0 | 按上述约定复现原式的不连续右端 |
| `tanh` | 逐分量 `tanh(v_i/epsilon_v)` | CSim 建议的平滑近似；不是论文原公式 |

`tanh` 模式要求有限正的 `epsilon_v`，单位 m/s，数值需随实验记录。
它在零速附近引入约 `K0/epsilon_v` 的等效线性斜率；epsilon 过小会增加数值刚性，不能只靠平滑就认定大步长可靠。
比较平滑近似与原式时，应同时研究步长和 epsilon 的影响，并对所有 RK 阶段重算阻力。
固定步长 RK4 跨过 exact 模式的速度换向点可能发生抖振或虚假增能；该模式不保证仍有经典光滑 ODE 的四阶收敛。
若需严格停止/粘着行为，需要另建静摩擦互补条件或事件规则；`sign(0)=0` 和 tanh 都不提供完整静摩擦机制。

### 6.2 耗散关系与验收

无风、K2/K1/K0 非负时，按逐分量 sign 约定可直接推导：

```text
F_d·v_L = -0.5*K2*norm(v_L)^3 - K1*norm(v_L)^2
          - K0*(abs(vx)+abs(vy)+abs(vz)) <= 0
```

tanh 模式对应 `-K0*sum(v_i*tanh(v_i/epsilon_v))`，同样非正。
有风时此不等式针对相对空气速度成立，对地机械能仍可能因风做功而增加。
固定悬点、零控制且无风的单摆应验证能量衰减；移动悬点或受控无人机不能只检查总能量单调下降，而要核对输入功率与阻力耗散。

物理验收清单（当前自动测试覆盖零系数、受力/径向张力、耗散、时变风收敛及失败原子性；五组论文参数实物对照仍需原始数据）：

1. 关闭阻尼后保持原单摆/耦合基准；零系数退化、速度反向及 `v=0` 的行为明确。
2. 检查阻力功率非正、单位正确、逐分量语义和坐标转换；不能将阻力误用成加速度或力矩。
3. 检查同一时刻的摆角式与单位向量式给出相同的加速度和张力，尤其包含非零径向阻力及移动悬点。
4. 无风固定悬点比较五组论文系数的摆幅衰减；无原始轨迹时只报告模型间差异，不填报“复现 RMSE”。
5. 检查 `T>0`、单位方向、切向速度、作用反作用及步长收敛；模式越界保留原状态并报告失败。
6. exact 与 tanh 分别验收换向、零速尾段及极端参数，记录 epsilon、步长、初值和 wind 配置。

## 7. 原文排版与复现校核记录

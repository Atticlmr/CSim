# 阶段 2：开发最小数学基础库

[返回开发总览](../development-workflow.md) · [日常开发流程](daily-workflow.md)

## 目标

建立可独立验证的向量、矩阵、线性求解和旋转基础。

## 当前交付

已实现 [Vector3 接口](../vector3.md) 和五组独立测试，并接入 `xmake test` 与 CI。
已实现 [固定大小矩阵接口](../matrix.md) 和六组独立测试，支持非方阵乘法、转置、单位矩阵及 `Matrix3 * Vector3`。
已实现 [LU 分解与线性求解](../lu.md) 和七组独立测试；基础库不直接导出到 Python。
已实现 [旋转矩阵与四元数](../rotation.md)、八组 C++ 测试，包含机体角速度到四元数导数的接口。
本阶段的最小数学基础已完成；阶段 3 的 RK4 也已完成首个里程碑。

## 前置条件

先明确各数学类型的语义；旋转相关接口遵循阶段 1 的约定。

## 实施内容

按固定大小向量 → 小矩阵 → 线性方程求解 → 旋转矩阵与四元数的顺序实现。
初期统一使用 `double`，先保证正确性，再考虑泛型扩展、动态矩阵、稀疏计算和性能优化。

每实现一项功能，同时在 `tests/math/` 增加验证：

| 功能 | 验收重点 |
| --- | --- |
| 向量 | 加减、缩放、点积、叉积和范数的已知结果；零向量归一化的处理 |
| 矩阵 | 已知乘法结果、单位矩阵和转置性质 |
| 线性求解 | 相对于问题规模的残差、主元选取、奇异与近奇异情况的处理 |
| 旋转 | 正交性、旋转前后向量长度、已知旋转方向、四元数与矩阵转换一致性 |

## 交付与验收

公共接口、实现及独立测试目标；浮点比较使用有依据的绝对或相对容差，测试失败返回非零退出码，debug 和 release 下的检查都有效。

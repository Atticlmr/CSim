## 实施内容

viewer 通过仿真接口读取状态快照，依次加入坐标轴、无人机简化模型、绳索、吊载和运动轨迹。
Python 实验和 viewer 使用相同的 C++ 状态约定；优先支持读取 Python 实验保存的轨迹，实时调用方式再按需要设计。
随后实现相机旋转与缩放、暂停、继续和单步推进。

仿真步长与渲染帧率分开；单线程初期可以累计时间，按固定步长推进仿真，再绘制当前状态。
明确计算跟不上实时进度时的处理策略，不能通过任意增大积分步长追赶画面。
物理计算保持 `double`，在渲染边界按需转换为 `float`。

未来 [PX4/APM 在环接入](../flight-controller-integration.md) 使用独立无窗口后端和快照订阅。当前内嵌演示的墙钟预算不能复用为 SITL/HITL 调度器，窗口暂停与飞控全系统暂停必须分开。

## 交付与验收

画面与记录数据一致，坐标转换方向正确；改变绘制频率不改变相同仿真时间下的数值结果，命令行仿真仍可独立运行。
物理正确性由测试、误差和约束验证，画面用于观察运动行为。

# 吊载无人机坐标系调研

调研日期：2026-09-09。

本文比较代表性论文与飞控/机器人软件约定，为阶段 1 提供选型依据。
以下保留调研时的结论和项目建议。2026-09-10 起，初版开发约定见 [建模约定](../modeling-conventions.md)。
本次未进行全领域文献统计，不据此断言某一约定占多数。

## 结论

吊载无人机没有专属且统一的坐标系标准。常见做法是组合使用世界/惯性系、无人机机体系以及绳索方向表示。
若吊载为刚体，再增加吊载自身的机体系。世界系 Z 轴向上与向下的论文都存在。

工程上可优先按对接对象选型：PX4 使用 NED/FRD 约定，ROS 使用 ENU/FLU 约定；具体消息的定义仍是接口依据。
两套约定都是右手系。[PX4 官方坐标约定](https://docs.px4.io/main/en/ros2/user_guide#ros-2-px4-frame-conventions)、[ROS REP-103](https://github.com/openrobotics/reps/blob/main/_posts/rep-0103.md)。

## 世界系与机体系的区别

| 用途 | 名称 | X 轴 | Y 轴 | Z 轴 |
| --- | --- | --- | --- | --- |
| 世界/导航系 | NED | 北 | 东 | 下 |
| 世界/导航系 | ENU | 东 | 北 | 上 |
| 无人机机体系 | FRD | 前 | 右 | 下 |
| 无人机机体系 | FLU | 前 | 左 | 上 |

世界系原点固定在选定的参考位置；机体系通常以无人机质心为原点，随飞行器平移和转动。
在短距离仿真中，可以把地面固定的局部世界系近似当作惯性系，需在模型假设中记录这一近似。

NED 与 ENU 包含水平轴的地理方向。若只规定 Z 轴向上、水平轴按试验场地任意选择，应称为“局部 Z-up 世界系”，不能直接认定为 ENU。
同理，仅规定 Z 轴向下也不能据此认定为地理 NED。

## 代表性来源

| 来源 | 可确认的约定 | 建模启示 |
| --- | --- | --- |
| Sreenath、Lee、Kumar，CDC 2013 | 用旋转矩阵表示机体到惯性系的变换，绳索单位向量从无人机指向吊载；由势能和自由落体方程可推断惯性系第三轴向上，推力沿机体正第三轴 | 不能将几何控制论文一概视为 NED；该文未在所引用定义中将水平轴指定为东、北 |
| Lee，2014，多机运输刚体吊载 | 明确惯性系第三轴沿重力向下，无人机第三轴向下，推力为负第三轴方向；为刚体吊载另设机体系 | Z-down 约定可用于几何控制，也可扩展到多机与刚体吊载 |
| Wang 等，2022，IET | 明确使用 NED 惯性系；机体轴前、右、下，绳索向量从无人机指向吊载 | 直接展示 NED/FRD 在单机吊载模型中的使用 |

第一行的 Z-up 判断是根据原文公式作出的推断：势能为 `m g e3 · x`，自由落体满足 `dv/dt = -g e3`，推力为 `f R e3`。
第二行文献明确规定第三轴向下，但没有据此规定水平轴必须对齐地理北、东。
来源：[CDC 2013，表 I 与第 II 节](https://hybrid-robotics.berkeley.edu/publications/CDC2013.pdf)、[Lee 2014，第 II 节](https://arxiv.org/pdf/1403.3684)、[Wang 等 2022，第 2.1 节](https://ietresearch.onlinelibrary.wiley.com/doi/10.1049/cth2.12301)。

## 绳索和吊载的表示

对于第一版的质点吊载与绷紧直绳，建议以世界系中的单位向量 `s_W` 表示从无人机悬挂点指向吊载的方向。
这是方向状态，只有两个自由度，不等于一个具有完整三轴姿态的刚体坐标系。代表性几何控制模型将这一方向写作 `q ∈ S²`。[CDC 2013，表 I 与第 II 节](https://hybrid-robotics.berkeley.edu/publications/CDC2013.pdf)。

以下为建议采用的几何定义与由此推导的受力符号：

```text
p_Q_W   无人机质心在世界系中的位置
r_QA_B  从无人机质心到悬挂点的偏移，分量在机体系中表达
R_WB    将机体系向量分量变换到世界系：v_W = R_WB * v_B
p_A_W   悬挂点在世界系中的位置
p_L_W   质点吊载在世界系中的位置
l       绷紧绳长，l > 0
T       张力大小，T >= 0

p_A_W = p_Q_W + R_WB * r_QA_B
s_W   = (p_L_W - p_A_W) / l
p_L_W = p_A_W + l * s_W
|s_W| = 1

绳索作用于无人机的力： F_Q_W = +T * s_W
绳索作用于吊载的力：   F_L_W = -T * s_W
绳索对无人机质心的力矩：tau_B = r_QA_B × (R_WB^T * F_Q_W)
```

静止悬垂时，NED 中 `s_W = (0, 0, 1)`，Z-up 中 `s_W = (0, 0, -1)`。
这些公式假定绳索绷紧且吊载为质点；松弛后不能继续用绳长等式计算方向状态。

质点吊载不需要独立姿态；若扩展为有尺寸和转动惯量的刚体，则需定义吊载质心位置、吊载机体系、姿态和悬挂点偏移。
这一结构可参考 [Lee 2014 的刚体吊载定义](https://arxiv.org/pdf/1403.3684)。

可以用两个摆角作图或定义局部模型，但必须规定旋转顺序和正方向。
建议三维大摆角模型使用单位向量作为方向表示，并验证其单位长度约束；几何表示避免局部角参数化的奇异问题。[CDC 2013](https://hybrid-robotics.berkeley.edu/publications/CDC2013.pdf)。
代码中建议用 `cable_direction_W` 命名绳索方向，以免与姿态四元数混淆。

## 两套约定的符号与转换

令 `e3 = (0, 0, 1)`、`g > 0`，`f >= 0` 为正常多旋翼的总推力大小，`R_WB` 为机体到世界的旋转矩阵。
下表根据各坐标轴定义推导，机体推力假定与第三轴共线：

| 量 | NED 世界系 + FRD 机体系 | ENU 世界系 + FLU 机体系 |
| --- | --- | --- |
| 世界系重力加速度 | `+g * e3` | `-g * e3` |
| 世界系推力 | `-f * R_WB * e3` | `+f * R_WB * e3` |
| 静止悬垂绳索方向 | `+e3` | `-e3` |

相同原点、轴严格对齐地理方向时，向量转换可写为：

```text
v_ENU = C * v_NED          v_FLU = D * v_FRD

    [ 0  1  0 ]               [ 1  0  0 ]
C = [ 1  0  0 ]           D = [ 0 -1  0 ]
    [ 0  0 -1 ]               [ 0  0 -1 ]

R_ENU_FLU = C * R_NED_FRD * D^T
```

这里 `D^T = D`。以上矩阵由轴定义推导，与 [PX4 描述的世界系和机体系转换](https://docs.px4.io/main/en/ros2/user_guide#ros-2-px4-frame-conventions) 一致。
位置原点不同还需平移；水平轴未对齐地理方向还需考虑相应旋转。
姿态转换需要同时处理世界系和机体系的变化，不能只把位置的 Z 分量取反。
四元数接口另需明确分量存储顺序、乘法约定和变换方向。

## CSim 选型建议

根据当前阶段，建议优先采用局部 Z-up 世界系 + FLU 机体系；若明确水平轴为东、北，则采用 ENU 命名。
理由是现有 viewer 已约定 Z-up，当前重点是自研数值算法、物理模型与独立仿真，并没有已确定的 PX4 接口需求。
这是项目工程建议，不是论文统计结论，也不是已实施的坐标决策。

如果近期目标转为 PX4 联调，则优先考虑动力学核心使用 NED + FRD，并在 viewer 边界统一转换为 Z-up。
如果主要复现某篇论文，则先保持该论文的完整约定，重点核对重力、推力、旋转方向与绳索方向，避免混用不同论文的符号。

最终选择时应在阶段 1 中确定：

- 世界系原点、水平轴方向与机体轴方向。
- 所有位置、速度、角速度、力和力矩所属坐标系。
- `R_WB` 及四元数的变换方向和表示约定。
- 绳索向量的起点、终点，以及悬挂点相对质心的偏移。
- 世界系、机体系、显示系及后续外部接口的转换边界。

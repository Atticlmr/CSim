# 第一版建模约定

版本：0.1，记录日期：2026-09-10。
本文是动力学实现的约定；当前已实现向量、通用固定大小矩阵、LU 求解和 [旋转/四元数接口](rotation.md)，[RK4](rk4.md) 已实现并验证数值算例，[固定悬点平面单摆](pendulum.md) 与 [无吊载无人机](drone.md) 已有独立模型及仿真接口，[无人机/吊载耦合](suspended-payload.md) 已实现无阻尼绷紧基准。
参考 [论文坐标系调研](development/coordinate-frames-research.md)，采用惯性系、无人机机体系与绳索单位方向的建模结构。

## 坐标与单位

| 名称 | 原点 | 轴向 | 用途 |
| --- | --- | --- | --- |
| 世界/惯性系 W | 试验场地选定的固定参考点 | 右手系，Z 向上；X 为场地参考方向，Y 由右手规则确定 | 位置、线速度、重力、绳索方向 |
| 无人机机体系 B | 无人机质心 | FLU：X 向前、Y 向左、Z 向上 | 角速度、惯性矩阵、控制力矩、连接点偏移 |
| 显示世界系 | 与 W 相同 | 与 W 相同 | viewer 场景位置 |

水平轴不绑定地理方向，因此 W 不命名为 ENU。短距离仿真忽略地球曲率与自转，将地面固定系近似视为惯性系。
长度、质量、时间、力、力矩分别使用 m、kg、s、N、N·m；动力学角度使用 rad，角速度使用 rad/s。
viewer 的视场角配置仍可用度，但转换发生在渲染接口，不能作为动力学角度直接使用。

向量名后缀 `_W`、`_B` 表示分量所属坐标系。仅能对同一坐标系且单位兼容的向量进行加减。
`Vector3` 本身不检查坐标系或单位，由模型接口负责约束。

## 姿态约定

`R_WB` 把机体系向量分量转换到世界系：`v_W = R_WB * v_B`；反向变换为 `v_B = R_WB^T * v_W`。
矩阵各列是机体三个单位轴在世界系中的表示，满足 `R_WB^T * R_WB = I`、`det(R_WB) = +1`。

姿态四元数记为 `q_WB`，存储顺序为 `(w, x, y, z)`，采用 Hamilton 乘法和单位长度约束。
向量变换定义为 `(0, v_W) = q_WB ⊗ (0, v_B) ⊗ conjugate(q_WB)`。
组合 `q_WB = q_WA ⊗ q_AB` 表示先从 B 到 A，再从 A 到 W。
机体角速度为 `Omega_B` 时，运动学约定为 `dq_WB/dt = 0.5 * q_WB ⊗ (0, Omega_B)`。

正转角遵循右手规则。姿态为单位旋转时机体系与 W 对齐；零航向时机头沿 W 的正 X，正航向绕 W 的正 Z 旋转。
Euler 角仅用于显示/输入，约定 `R_WB = Rz(yaw) * Ry(pitch) * Rx(roll)`；内部姿态使用四元数或旋转矩阵。

## 第一版物理范围

- 单无人机为刚体，质量和机体系惯性矩阵为常量。
- 吊载为质点，不具有需要独立积分的自身姿态或转动惯量。
- 绳索无质量、不可伸长，第一版只实现绷紧模式；基准配置无弹性、阻尼、空气阻力和碰撞。
- 吊载模型已支持通过 DragConfig 显式选择线性、二次及含 SPAD 的综合等效阻力，默认关闭；[论文解析](zhu-2025-payload-model.md) 与 [风场实现](aerodynamics.md) 记录受力约定。SPAD 不增加绳索伸长自由度。
- 绳索悬挂点 A 与无人机质心 Q 重合，机体系偏移 `r_QA_B = 0`；偏心悬挂留待后续扩展。
- 刚体以总推力和质心处的控制力矩受力；仿真层已支持受约束四旋翼分配及推力一阶响应，尚无电机转速模型。
- CTBR、单旋翼推力、角速度内环与响应延迟已作为独立 Python 层实现，见 [控制接口与响应模型](control-and-response-models.md)；不能以角速度指令替换真实角速度状态。
- 初始状态必须满足绳长、单位方向及切向速度约束；绳索不能承受压力。

## 状态、输入与参数

以下为语义约定，暂不固定序列化或内存布局。无吊载模型中 `p_Q_W/v_Q_W` 对应 `position_W/velocity_W`，`Omega_B` 对应 `angular_velocity_B`，`J_B` 对应 `inertia_B`，`f/tau_control_B` 对应 `thrust/torque_B`：

| 符号 | 意义 | 坐标系/单位 |
| --- | --- | --- |
| `p_Q_W`、`v_Q_W` | 无人机质心位置、线速度 | W，m、m/s |
| `q_WB` | 机体到世界的单位四元数 | 无量纲 |
| `Omega_B` | 无人机角速度 | B，rad/s |
| `s_W` | 从悬挂点指向吊载的单位方向 | W，无量纲 |
| `omega_c_W` | 绳索方向的最小角速度，满足 `omega_c_W · s_W = 0` | W，rad/s |
| `f` | 沿机体正 Z 的总推力大小，`f >= 0` | N |
| `tau_control_B` | 关于无人机质心的控制力矩 | B，N·m |
| `m_Q`、`m_L` | 无人机与吊载质量，均为正 | kg |
| `J_B` | 无人机关于质心的对称正定惯性矩阵 | B，kg·m² |
| `l` | 绷紧绳长，`l > 0` | m |
| `g` | 重力加速度大小，`g > 0`，默认 9.80665 | m/s² |

绳索方向命名为 `s_W`，代码使用 `cable_direction_W`，与姿态四元数区分。
当前耦合状态采用 `(p_Q_W, v_Q_W, q_WB, Omega_B, s_W, omega_c_W)`；吊载位置、速度由几何关系计算，不重复独立积分。
张力 `T` 是约束动力学求出的量，不是独立控制输入或需要积分的状态。
当前无人机的线加速度和角加速度同样由受力及状态求出，已在物理快照中提供，但不作为独立积分状态；[状态与导数说明](drone.md#独立状态导数与加速度) 给出两者区别。

## 几何与受力符号

第一版悬挂点与机体质心重合：

```text
p_A_W = p_Q_W
ds_W/dt = omega_c_W × s_W
p_L_W = p_Q_W + l * s_W
v_L_W = v_Q_W + l * (omega_c_W × s_W)

g_W = (0, 0, -g)
F_thrust_W = R_WB * (0, 0, f)
F_cable_on_drone_W = +T * s_W
F_cable_on_load_W  = -T * s_W
```

连接点在质心时，轴向绳索张力对无人机质心不产生力矩。
后续加入偏心悬挂时，需同时修改几何、速度、动力学与张力求解；几何起点为 `p_A_W = p_Q_W + R_WB * r_QA_B`，绳索力矩为 `r_QA_B × (R_WB^T * F_cable_on_drone_W)`，不能只修改显示位置。

启用 SPAD 等效阻力后，阻力作用于吊载，其径向分量参与张力求解；不能只给摆角方程添加衰减而保留无阻尼张力。
原论文向下世界系到本项目 Z-up 系的转换、带阻力的闭合张力式及速度定义见 [Zhu 等模型解析](zhu-2025-payload-model.md)。

## 模型验收基准

- 静止悬垂方向为 `s_W = (0, 0, -1)`；无人机受绳索向下拉，吊载受绳索向上拉。
- 无风静止悬停时：单位机体姿态、`T = m_L * g`、`f = (m_Q + m_L) * g`、控制力矩为零。
- 绳索两端作用力在同一坐标系中相加为零，质心悬挂下绳索力矩为零。
- 绷紧模式满足 `|s_W| = 1`、`omega_c_W · s_W = 0`，且吊载与无人机距离为 `l`。
- 正 90° 航向把机体正 X 映射到世界正 Y，机体正 Z 保持向上。
- 模型只支持正张力的绷紧阶段；检测到张力降至零或求解要求负张力时，报告模式边界并停止当前算例。不得静默把负张力截为零后继续使用绷紧方程。

矩阵与姿态测试已验证正 90° 航向、组合顺序、矩阵/四元数一致性，并通过 `Rdot = R * skew(Omega_B)` 检查角速度导数约定。
固定悬点单摆已通过周期、能量和几何约束验证；无吊载无人机已通过自由落体、`f=m_Q*g` 悬停、倾斜推力、三轴力矩响应及转动守恒收敛检查。
上述吊载耦合基准已加入测试，并验证自由落体中绳方向匀速旋转的解析轨迹、四阶收敛和恒推力外力功平衡。初值与每步的张力都必须为正，创建/重置耦合仿真时需显式初始控制，见 [耦合模型范围](suspended-payload.md)。

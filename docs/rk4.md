# 固定步长 RK4

已实现 [`csim::numerics::rk4Step`](../include/csim/numerics/rk4.hpp)，使用经典四阶段、四阶显式 Runge–Kutta。
它适用于显式 ODE 的一次正向推进；固定步长没有内置误差估计，也不保证任意步长下稳定。
自适应替代方法见 [Dormand–Prince](dormand-prince.md)，其他候选方法的预留接口见 [积分算法调研](numerical-integration.md)。

## C++ 接口

```cpp
#include <csim/numerics/rk4.hpp>

const auto decay = [](double /*t*/, double x, double rate) {
    return -rate * x;
};
double x = 1.0;
x = csim::numerics::rk4Step(0.0, x, 2.0, 0.1, decay);
```

参数顺序是 `rk4Step(t, state, control, dt, dynamics)`，返回新状态，时间由调用方推进。
动力学回调为 `dynamics(t, const State&, const Control&) -> State`，一个积分步内使用同一个控制输入。
若控制器按离散周期更新，应在完整步边界执行；不能把会改变控制器内部状态的更新塞进四次 RHS 计算中。

| 状态要求 | 说明 |
| --- | --- |
| 加法与右侧标量乘法 | 支持 `a + b`、`a * double`，结果能构造成 `State` |
| 有限性检查 | 浮点标量使用 `std::isfinite`，自定义状态提供 `bool isFinite() const`，检查全部分量 |
| 值语义 | 中间结果独立存储；无需默认构造、`+=`、除法或连续内存布局 |
| 状态与导数表示 | 此接口使用同一种分量类型；组合状态的加法和缩放由其自身提供 |

已验证 `double`、`Vector3`、固定大小 `Matrix`、`Quaternion` 及不可默认构造的位置/速度组合状态。
积分器不会将输入状态或控制重新赋值；回调以左值调用，不复制，也不在子阶段间反复移动，支持不可复制的函数对象。
回调应按传入参数计算导数。用户回调对外部对象的副作用，以及自定义状态中的共享可变存储，不在积分器的回滚保证之内。

## 四个阶段

```text
k1 = f(t,        x,            u)
k2 = f(t + h/2,  x + h*k1/2,   u)
k3 = f(t + h/2,  x + h*k2/2,   u)
k4 = f(t + h,    x + h*k3,     u)
x_next = x + h*(k1/6 + k2/3 + k3/3 + k4/6)
```

导数先加权再求和，避免直接计算 `k1 + 2*k2 + 2*k3 + k4` 的可避免溢出；最后乘 `h`，避免先计算极小 `h/6` 导致步长权重下溢。
这不是任意数值范围下的精确算术：浮点舍入、微小分量下溢及状态运算的中间溢出仍可能发生。
返回有限结果不等于精度已满足要求；应通过缩小步长和解析解/独立参考解验证。

## 数值与异常约定

| 情况 | 处理 |
| --- | --- |
| `t` 非有限；`dt` 非有限、零或负数 | `std::invalid_argument` |
| 初始状态含 NaN/Inf | `std::invalid_argument` |
| 中点、端点无法形成有限且严格递增的 `t < t+h/2 < t+h` | `std::overflow_error`，包含步长太小导致时间无法前进的情况 |
| 任一阶段状态、导数或最终结果非有限 | `std::overflow_error`，立即停止后续阶段 |
| 动力学回调或自定义状态运算抛出异常 | 原样向上传播，不吞掉，也不返回部分结果 |

时间与初值检查在首次调用 RHS 之前完成。零步长不会被当作一次成功推进，负时间起点可以使用，但不支持负步长逆向积分。
严格递增检查只能检测时间坍缩，不能消除大时间起点的舍入；尽量使用合理尺度的局部仿真时间。
通用 `Control` 可能不是数值类型，由模型负责验证控制、物理约束、参数与状态的物理有效性。
有限性检查也不保证四元数为单位长度、绳索张力为正或绳长约束成立。

## 姿态归一化策略

通用 RK4 不投影、不归一化。`Quaternion{}` 是单位旋转，不是零导数；算法直接初始化每个导数，不构造默认零累加器。
机体系角速度使用现有 `q.derivativeBodyRate(omega_B)`，即 `qdot = 0.5*q*(0, omega_B)`。
若应用需要归一化，采用 `rk4Step(...).normalized()`，仅在完整一步之后执行，绝不能归一化导数。

测试同时比较原始分量积分与每步后归一化：记录模长漂移和旋转误差。
此策略对恒定角速度已验证，不替代后续耦合无人机/绳索系统的约束和收敛验收。
不会因为归一化得到单位长度，就宣称积分具有辛性质或精确能量守恒。

## 解析解与收敛记录

本地 C++ 测试使用指数衰减 `x'=-2x, x(0)=1, T=1`；姿态使用
`q0=fromRollPitchYaw(0.7,0.2,-0.4)`、`omega_B=(0.4,-0.6,0.8)`、`T=2`。
姿态解析解为 `q0 * fromAxisAngle(omega_B, |omega_B|*T)`；零角速度单独验证。
角误差由相对单位四元数计算 `2*atan2(|vector_part|, |w|)`，避免小角度下 `acos` 的精度损失，并考虑 `q/-q` 等价性。
以下为本机双精度检查的近似值，末尾位可能随编译器与累计时间舍入略有变化。

| 步长 | 衰减绝对误差 | 姿态原始模长漂移 | 姿态角误差（rad） |
| --- | --- | --- | --- |
| 0.2 | 8.07314e-5 | 1.08238e-7 | 2.40543e-6 |
| 0.1 | 4.26519e-6 | 3.38613e-9 | 1.50808e-7 |
| 0.05 | 2.45185e-7 | 1.05845e-10 | 9.43281e-9 |

衰减误差缩小约 18.9、17.4 倍，随步长减小趋近四阶的 16 倍；姿态角误差约缩小 16 倍。
逐步归一化将模长恢复至浮点精度，恒定角速度算例中的角误差与原始积分基本一致。
自由落体比较 `p=p0+v0*T+g*T²/2`、`v=v0+g*T`，绝对误差不超过测试的 `1e-12` 容限；此多项式解不适合单独证明四阶收敛。

[`rk4_test`](../tests/numerics/rk4_test.cpp) 包含七组检查，覆盖阶段时刻/状态/控制、不复制回调、非自治方程、收敛、状态类型、姿态策略、异常与极端数值。
检查不依赖 `assert`，Release 下仍有效。积分算法不要求 Python 绑定测试。
